# Заказ еды в ресторане с доставкой

**Участники (роли):** Клиент, Оператор ресторана, Повар, Курьер, Платёжная система

**Шаги процесса:**

1. Клиент открывает приложение и выбирает блюда из меню.
2. Клиент оформляет заказ и указывает адрес доставки.
3. Система проверяет доступность выбранных блюд на складе.
4. Если блюда недоступны — клиенту предлагается изменить состав заказа (условие ветвления №1).
5. Клиент производит оплату через платёжную систему.
6. Если оплата не проходит — заказ отменяется, а клиент получает уведомление об ошибке (условие ветвления №2).
7. После успешной оплаты заказ передаётся на кухню повару.
8. Повар начинает готовить заказанные блюда.
9. Параллельно с приготовлением оператор ресторана ищет свободного курьера для доставки (параллельное действие).
10. Как только блюда готовы, курьер забирает заказ из ресторана.
11. Курьер доставляет заказ по указанному клиентом адресу.
12. Клиент получает заказ и подтверждает его получение в приложении.
