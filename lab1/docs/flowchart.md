# Flowchart — Проверка возможности оформления заказа

Блок-схема алгоритма проверки заказа перед передачей на кухню.

```mermaid
flowchart TD
    A[Начало] --> B[Клиент выбрал блюда]
    B --> C{Блюда есть в наличии?}
    C -->|Нет| D[Предложить изменить заказ]
    D --> B
    C -->|Да| E[Рассчитать стоимость заказа]
    E --> F{Сумма заказа больше минимальной?}
    F -->|Нет| G[Сообщить о минимальной сумме заказа]
    G --> B
    F -->|Да| H[Отправить заказ на оплату]
    H --> I[Конец]
```

**Элементы:** старт, условия ветвления (наличие блюд, минимальная сумма заказа), обработка каждого условия и завершение алгоритма.
